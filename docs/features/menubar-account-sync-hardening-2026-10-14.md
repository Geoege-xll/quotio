# 菜单栏账号额度同步审计与修复

日期：2026-10-14。范围：融合账号页与 macOS 菜单栏之间的账号身份、固定选择、额度读取和刷新生命周期。

## 已确认的问题及修复

| 问题 | 具体触发 | 修复后的行为 |
| --- | --- | --- |
| 同账号重复固定 | CPA 启动后额度迁为运行键，但自动选择又加入旧磁盘邮箱键 | 候选只取当前模式的目录，目录与额度使用同一份安全别名映射；新旧键合并，保持用户已有顺序 |
| 同邮箱凭据串号 | 两个凭据共用显示名，只有其中一个取得额度 | 不再按显示名猜归属；只有精确键或目录确认的一对一旧身份可以读取额度 |
| 不同认证目录误迁移 | 本地与 CPA 的同名文件具有明确不同路径 | 删除第二套独立文件名迁移，统一遵守 `AuthFileIdentity` 的路径及碰撞规则 |
| 旧选择被裁剪 | 旧 Copilot 提供商名、旧 login、Codex 邮箱及单密钥 GLM 连接名称 | 规范化旧提供商名；当前目录确认的唯一旧身份迁为规范键，保留“已手动选择”偏好 |
| GLM 只能操作首密钥 | 一个连接配置多个 Key | 同一固定图标打开逐密钥菜单；警告确认保留实际目标 Key，单密钥保持原按钮 |
| 请求失败导致固定项丢失 | 已配置的 GLM Key 暂无额度，下一次同步裁剪它 | 有效候选包含启用配置的 Key，不依赖额度成功；没有数据时沿用未知值显示 |
| 删除后账号重新出现 | CPA 目录或额度响应在删除后迟到 | 目录和额度都检查读取前的账号世代；按文件名删除时清理全部运行索引、额度、套餐和固定项 |
| 停服后出现旧磁盘快照 | CPA 删除文件但直读目录仍持有旧记录 | 立即移除明确同路径快照；API 成功后重新扫描本地目录，明确不同目录的文件保留 |
| 删除 GLM 后旧数据残留 | 连接移除但额度、套餐、固定项或在途请求仍存在 | 删除所有实际移除 Key 的关联数据，推进账号世代，拒绝旧响应回填 |
| 编辑密钥后沿用旧额度 | GLM 或 ClinePass 原槽位更换凭据 | 清旧额度；UUID／名称身份未变时保留固定选择，未改 Key 的额度保留，保存后的刷新等待可用槽位 |
| 两个入口刷新内容不同 | 菜单只刷额度，账号页另行扫描目录、补 Grok／Devin | 共用 `AccountRefreshStep` 与 `manualRefresh()`，同轮点击合并 |
| 后台刷新驱动菜单进度圈 | 自动轮询使菜单刷新按钮旋转并禁用 | 用户刷新状态由 ViewModel 持有，账号页与菜单共用；后台忙碌仍保留独立状态提示 |
| 停止代理也停止额度同步 | `stopProxy()` 取消刷新任务却不重新调度 | 停服后按原频率恢复直读额度轮询；手动频率仍不自动刷新，取消休眠不再额外发一次请求 |
| 等待期间切模式仍执行旧任务 | 用户刷新等待后台槽位时切模式或启停代理 | 预约前记录来源，成功预约后验证模式／运行会话并保证释放；批次提交也检查账号世代 |

## 身份与兼容边界

- `MenuBarAccountCatalog` 统一生成候选、旧身份映射和额度解析。CPA 运行时使用当前 CPA 目录；停服使用直读目录；监控模式使用有效监控目录。独立额度缓存继续保留。
- 同邮箱多凭据管理行不再提供误导性的固定入口；独立缓存行仍可固定。显示名只用于展示。
- 监控模式仅在当前目录确认规范键时兼容直读文件的明确旧身份。Codex 同邮箱多套餐产生歧义时不指定其中一个套餐。
- GLM 旧名称只有“配置名唯一、启用、仅含一个 Key”时迁移到 UUID Key。多 Key 旧名称无法证明来源，保留独立缓存，不归到首 Key。
- 新旧固定项去重保留原顺序，不重置用户手动选择标记、数量上限、隐私及已用／剩余偏好；不改写认证文件或密钥 UUID。
- CPA 删除接口仍按原文件名调用；展示规范化不修改接口参数。删除多个索引只清理被删除文件的键，明确不同路径的本地文件保留。

## 刷新流程

| 当前来源 | 共用全量刷新步骤 |
| --- | --- |
| 监控模式 | 监控目录与额度刷新 |
| CPA 运行 | CPA 目录 → 全部额度 → Grok → Devin |
| 本地代理停服 | 直读目录 → 本地额度 → Grok → Devin |

用户任务等待实际额度槽位；后台重复请求继续合并。菜单重建或关闭主窗口不会重置 ViewModel 的用户刷新状态。账号页保留直接点击全量刷新和下拉按服务商刷新。

已检查既有通知链：额度字典数值变化仍通过合并通知更新状态栏及菜单，主窗口关闭不影响该链路。仅目录／选择变化也明确通知；Claude／Codex 主额度与模型专属限额继续分开。
