# CPA 仪表盘总览与分析重构

## 页面与导航

- 仪表盘直接展示总览、用量趋势、用量分布，不再使用大折叠容器。
- CPA 卡片下统一展示时间、模型、提供商、来源、API 密钥、结果筛选，以及图表分组、指标菜单；趋势与用量分布不再保留独立筛选。
- 请求明细、价格统计通过仪表盘的系统 NavigationStack push，保留系统返回按钮。
- 子页继承首页筛选快照，返回不反向覆盖首页条件；模型排行可携带条件进入明细。
- 模型、提供商、账号来源、API 密钥共用横向条形图；名称、数值、占比固定宽度，条形占据剩余空间。

## 数据一致性

- 首页与明细共用 SQLite 事件索引、六维筛选及指标计算；成功率分母不包含取消请求。
- 4 小时、24 小时、今天、7 天、30 天、全部及自定义范围使用精确时间条件。
- 旧日归档先扣除事件索引已经覆盖的部分，再合并总览、日趋势和分布；保留真实历史总量，不补造明细。无法完整覆盖历史日桶的时间或元数据筛选显示覆盖说明及已知下界。
- 旧版 CPA 的进程累计保留为兼容展示，不伪装成可按时间筛选的事件明细。

## 性能边界

- CPA 采集周期保持两秒。统计修订号仅在数据或索引可用性变化时更新，空队列心跳不驱动聚合。
- 首页、价格页只在可见生命周期内运行任务，窗口不活跃时停止页面查询。
- 聚合查询最多每五秒检查一次变化，每分钟推进滚动时间窗；同条件保留旧结果，不反复显示加载占位。
- SQLite 在账本 actor 内完成聚合；总览不解码请求投影，不将完整事件历史搬到主线程。
- 趋势最多返回 240 个绘制点。排行默认前 8 项，按需增加，最多 1,000 项，更多记录仍可进入分页明细。
- 条形和趋势后台刷新不做位置、形状过渡动画；采集时间保持独立叶子视图。

## 价格统计范围

- 价格目录持久化到同一受保护数据库，单位为 USD / 百万 Tokens，按真实模型名匹配。
- 支持输入、输出、缓存读及缓存写单价编辑。可选缓存单价留空与显式零价含义不同。
- 使用上游基础公式：非缓存输入、输出、缓存读、缓存写分别计价，推理不再次相加。
- 缺缓存拆分且存在缓存用量、缺对应缓存单价或未配置模型价的请求不参与估算，单独展示覆盖率。
- 当前为手动标准单价估算，不是实际账单；尚不包含上游价格目录自动同步、别名价格回退、长上下文与服务等级加价规则。页面明确说明，不宣称完整价格规则等价。
