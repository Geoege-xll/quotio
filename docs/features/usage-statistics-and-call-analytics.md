## 当前行为

“用量统计”和“调用分析”在本地代理模式、监控模式均可使用。用量页读取 Claude Code、Codex、OpenCode 的真实客户端用量，顶部固定“综合／Claude Code／Codex／OpenCode”，不再用 CPA 提供商代替客户端。只展示 Token，不包含费用、价格或货币切换。

用量页默认“综合／全部”，来源和时间偏好跨重启保留。今日、本周、本月、全部控制摘要、日趋势、模型分布和明细，本周固定周一开始；热力图随来源切换，独立显示最近52周。页面保留彩色摘要、全年热力图、悬浮日详情、模型环形图、完整模型表、展开详情和各模型微型趋势。环形图展示前5名与其余模型合计，明细保留全部模型；零值不制造假扇区。窄窗口采用换行或横向滚动，图表可通过键盘及文字明细读取。

页面打开时导入现有本地历史，每分钟刷新；手动刷新可提前扫描，来源和日期切换只过滤已聚合数据。三个客户端并发读取，各来源完成后独立保存并显示，不再等待最慢来源才发布全部结果。底部按来源显示读取、保存、完成及文件进度；读取期间原刷新按钮变为取消，取消后保留已经完成的数据，可再次手动刷新。取消会同时暂停自动刷新，离开并重新进入页面后恢复自动刷新。来源缺失、读取不完整、合法零和保存失败分别呈现。已有历史不会因日志清理或暂时不可读消失。

调用分析对齐 AIUsage 的来源／时间两行控制台、自定义日期弹层及快捷范围、五项摘要、每日趋势、Top12排行、MCP服务下钻、代理会话分布、已用／未用项目和来源帮助。默认全部来源／本月，偏好持久化；自定义包括结束日并归一反向日期。MCP／技能／工具仅切换排行，不改变摘要与趋势口径。

代理分布按 Claude 主会话／子代理会话启动次数统计，纯文本、没有工具调用的会话也计入。使用结构化会话时间归属日期，复制日志或修改文件时间不改变该日期。旧归档无可靠日期的会话仅计入“全部”，有明确提示。成功率、耗时只使用真实已知样本；仅成功读取的来源能够生成未调用结论。

## 架构与数据口径

### 客户端用量

`ClientUsageSourceScanner` 为每个客户端提供独立 actor，`ClientUsageEngine` 并发调度来源，在每个来源完成后合并、持久化并生成日桶，`ClientUsageViewModel` 负责发布快照与页面刷新生命周期。取消或重新进入页面会切换刷新代次，旧任务排队中的通知不能覆盖新结果。`ClientUsageSnapshot` 只保存消息／会话散列和 Token 元数据，不保存提示词、工具参数、凭据或原始会话标识。使用私有目录、私有文件和原子替换，拒绝符号链接目标；旧账本损坏时不被空扫描覆盖。

- Claude Code：解析本地 assistant `message.usage`，按消息身份去重，流式多次更新保留更完整计数。缓存读取／创建补入规范输入。
- Codex：解析 sessions 与 archived 会话，保存脱敏累计检查点。合并历史后重新计算差额，扣除 fork 继承量；迟到前序事件可以下调既有差额，原日志删除后仍能重算。不能以历史差额的最大值代替重新计算。
- OpenCode：通过只读 SQLite 查询投影消息统计字段，读取已提交的 WAL，不复制完整数据库。输入加缓存读写形成规范输入；推理属于输出子项。

逐来源的 `ScanCache` 是可重建的脱敏扫描索引，永久账本仍是历史记录的保存位置。Claude 和 Codex 对未变化文件复用检查点，追加日志从已有游标继续读取；文件指纹和有限内容探针用于发现截断、替换及原位改写。Codex 缓存键统一 macOS `/var` 与 `/private/var` 的物理路径拼写，避免同一个文件写入和读取时使用不同索引。已保存但尚未并入永久账本的历史可从缓存重放。

Codex 首次扫描先筛选相关事件，避免对无关正文完整解码；合并永久检查点后只投影一次，消除逐事件复制会话数组的开销，并以二分查找定位 fork 的父累计量。未变化检查点在同一个引擎内复用已有投影和日桶。OpenCode 在数据库及 WAL 指纹不变时复用索引；有可靠版本字段时比较消息版本，仅投影变化消息，否则回退全量读取。SQLite 进度回调允许在单次查询执行过程中响应取消。

规范总量为输入与输出之和；缓存已包含于输入，推理已包含于输出，摘要不会再次把子项加入总量。非法类型、负数和越界数值标记读取不完整，不能伪装成可靠零。

### CPA 仪表盘

仪表盘的请求数／Token 保留独立 CPA 网关口径。`UsageStatisticsStore` 是唯一队列消费者，由应用／代理运行生命周期驱动，独立于窗口是否打开。新版使用单次 `/usage-queue` 请求；旧版回退到 `/usage` 累计快照，累计快照不重复叠加到事件账本。

`UsageLedger` 保存日×提供商×模型摘要。CPA 数据无法可靠关联请求客户端，因此不与客户端账本混加。同一次请求可能同时存在于客户端日志和网关记录，两页因统计范围不同而不要求数值相等。

队列读取即移除，与其它管理消费者共享。其它消费者取走、响应丢失、过期或落盘前终止无法保证补回。写盘失败时保留内存批次并暂停继续消费，优先重试保存。未采集和真实零分别显示。

### 调用分析

`CallAnalyticsEngine` 只读扫描客户端会话，OpenCode 使用只读 SQLite。归档保存日摘要与识别到的工具名称，不保存正文和参数。Schema 7 保留代理会话日期并兼容 Schema 6；未知日期历史以余量保留，补出日期后避免重复加总。

调用摘要采用已观察计数的高水位，重扫不重复累加，日志删除后保留历史。只有日摘要、缺少逐事件身份时，删除旧日志再产生新调用不能保证精确重建；未知会话日期也不能凭空恢复。Codex 技能识别仍基于 SKILL.md 读取等启发式证据。

## AIUsage 源码逐项对照与取舍

参考仓库为 `/tmp/quotio-aiusage-reference`，提交 `bdb83bbe077879855c03e656cbc2fe5890bd27e9`。以下结论来自该提交的实际源码。

| AIUsage 模块 | Quotio 对应实现 | 复刻或适配 |
|---|---|---|
| `ProxyStatsView`、`StatsDataAdapter` | `UsageStatisticsScreen`、`ClientUsageSnapshot` | 恢复真实客户端来源、持久化时间筛选；按用户要求统一 Token，移除费用。 |
| `ProxyStatsView+Summary`、`+Distribution`、`DashboardView+Heatmap` | `UsageStatisticsCharts`、`Distribution`、`Heatmap` | 复用页面结构、卡片、色阶、52周热力图、分布与明细；补足完整环形图合计、窄窗口与键盘读取。 |
| `AppSurfaceTokens` | `AnalyticsSurface`、`AnalyticsSegmentedControl` | 采用原生亮暗表面与等宽分段控件，适配 Quotio Observation 和四语言。 |
| `ClaudeProvider+ProxyArchive` | `ClaudeClientUsageSource` | AIUsage 当前 Claude 用量来自其 Gateway 永久归档；Quotio 没有同一档案，改读 Claude Code 本地用量，不声称覆盖其 Claude Desktop 网关范围。 |
| `CodexCostProvider+FileParsing` | `CodexClientUsageSource`、永久检查点 | 借鉴累计差额与 fork 扣除；保存检查点后重算，补强迟到前序、跨扫描及日志删除情况。 |
| `CodexCostProvider+Tracks` | 独立客户端账本 | AIUsage 排除自家代理日志再合并自家代理档案；Quotio 保留客户端日志，CPA 完全分账避免双计。尚未实现相同的代理／非代理轨道，不展示无对应数据的切换。 |
| `OpenCodeCostProvider+Database`、`+Parsing` | `OpenCodeClientUsageSource` | 保留 Token 计算规则，改用只读 SQL 统计投影，减少完整消息读取和数据库副本；因 CPA 分账，不排除 AIUsage provider 的客户端记录。 |
| `CallAnalyticsView`、`Rankings`、`ZeroCall`、`Derived` | 调用分析页面、展示模型与组件 | 对齐筛选、摘要、趋势、排行、下钻、库存和来源说明；恢复按日代理会话次数，包含纯文本子代理。 |
| `ProxyStatsView+Trend` 的 `selectedModels` | 模型微型趋势及总量趋势 | 参考提交的“对比”仅改变选中状态和行高亮，没有对比图消费；不复制该空壳交互，保留可用趋势。 |
