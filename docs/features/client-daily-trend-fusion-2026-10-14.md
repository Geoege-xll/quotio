## 日期与数值口径

`ClientAnalyticsDailyTrendData` 只组合已经筛选的日汇总，不查询数据库或回写账本。调用账本的公历本地日期按当前时区解析，与 Token 日桶对齐；选定范围补齐没有事件的日期，避免旧柱图仅排列有事件日期而压缩中间间隔。全部历史按两份数据日期的并集确定范围。

两图共用明确的连续日期范围、日期刻度和固定宽度的纵轴标签，防止 Token 数字较大时挤占横向空间。柱体以该日零点为中心，并从零起绘制高度；使用相邻本地日间距计算对称宽度，兼容夏令时的 23／25 小时日长。单日范围也保留合法绘图区，跨年范围在日期刻度中显示年份。

Token 与工具次数各自确定纵轴范围，没有双轴叠图或数值混加。来源不可用时对应指标保留未知；可用账本在某天没有观察到事件时显示零。原有读取异常与采集状态提示继续由页面提供。
