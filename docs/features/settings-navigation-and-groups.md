# 设置总览与二级分类页面

## 目标与边界

按 2026-09-07 确认的方案，将长表单改为“设置总览 → 分类页”，分为八类。总览仅显示搜索、状态摘要与入口，不重复放置可编辑设置。

此次迁移以功能保留为约束：复用原设置组件、配置键、Binding、保存函数和确认弹窗。没有改动配额采集、Token 聚合、CPA 字段定义或代理默认模型的归属。

以下清单记录源码迁移的目标与对应关系，不是已经执行的回归测试报告。

## 二级导航与搜索

- 设置总览按应用偏好、CPA 配置、安全与维护分区；宽窗口两列，窄窗口一列。
- 分类页占用现有主导航的内容区，不添加第三个永久侧栏。
- 根页面持有搜索文本，返回总览时不清空查询。
- 搜索使用 SettingsTopic 的真实卡片标识，支持中文和英文技术关键词。
- 搜索结果进入对应分类并滚动到目标卡片，使用边框提示定位结果。
- 只将目标分类的设置组件挂载到视图树，不在总览加载 CPA 配置或扫描 YubiKey。

## 配置归属与不可用状态

- 客户端偏好、CPA 共享设置及混合安全维护设置提供不同说明。
- CPA 分类入口始终可见；仅监控模式下显示说明并提供前往运行模式设置的入口，不自动切换模式。
- 本地代理停止时，端口、自动启动等既有本机配置仍可访问；依赖管理接口的设置保留服务不可用提示。
- 模型别名按钮同时检查运行状态和管理客户端，不通过浏览页面执行写入。
- AI 代理默认模型仍归属各代理的模型槽，模型策略页仅提供前往代理配置的快捷入口。

## UI 适配

SettingsCardSection 通过环境开关在新分类页使用 QuotioTheme 卡片；旧 Form 调用点仍可使用原生 Section。正文控件与说明不通过手工复制迁移，原有弹窗和任务继续附着在原设置组件上。

卡片使用连续圆角、细描边与现有阴影。输入框使用胶囊背景与焦点描边，并保留 TextField 的提交行为。外观、额度样式和用量聚合等选项使用统一胶囊选择器，空间不足时以菜单呈现相同的完整选项集合。

路径、地址和管理密钥使用可在窄窗口上下排列的标签容器。现有复杂的系统控件、模式卡片、硬件密钥配置弹窗和确认流程不在此轮重写。

## 保存反馈

代理配置继续使用原 loadConfig 和各项 save 函数。Scope 只限制展示范围。上游代理新增应用按钮，原回车保存仍保留。保存失败除原日志外增加可见弹窗，可重新加载服务器当前配置，不把失败显示成成功。

本轮不修改端口等设置原有的自动保存语义，也不统一替换全部配置项的持久化策略。

## 原生 macOS 导航修订

本节替代上文关于“大卡片总览、自定义卡片容器、手工两级导航”的实现说明，功能迁移清单中的业务约束继续有效。

- Apple macOS 规范是基础，产品风格在其上统一信息结构与表达，不强制覆盖系统控件。
- 应用模式移回设置首页，使用系统单选控件；保留模式说明、功能列表、原切换确认和初始化逻辑。
- 首页恢复单列原生分组导航行，使用系统搜索；取消总览大卡片、状态胶囊和手绘导航箭头。
- 设置内部使用单个 NavigationStack，分类和辅助页面使用系统 Push；返回按钮、标题和过渡由系统提供。
- 分类页恢复 Form/Section/LabeledContent；枚举选择恢复系统 Picker，输入框恢复系统样式。
- 局域网设置从服务 Section 内移为相邻 Section，保留原绑定及 onChange 回调，避免原生表单嵌套 Section。
- 管理密钥、日志、通知、菜单栏、刷新、配额与用量等原有操作不删减，配置键和保存函数不改动。
- 设置中的别名管理改为原生列表页，新增别名继续 Push 到表单；保留来源能力、思考等级、自动命名、搜索、刷新、计数、删除确认与错误提示，复用原 CPA ViewModel 和服务。
- YubiKey 配置改为 Push，复用原预检、PIN、管理密钥、风险确认、写入、失败刷新及成功后身份选用流程。其他调用点仍可使用原事务弹窗。
- 不可中断的别名写入或硬件操作期间暂时禁止导航返回，完成后恢复系统返回按钮。
- 设置中的关于、日志、代理页面入口进入导航栈，复用原业务页面，不再直接切换主侧栏。
