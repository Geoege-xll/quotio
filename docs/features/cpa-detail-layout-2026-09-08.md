# CPA 请求明细与价格统计：整页滚动、固定分页及表格样式

## 问题与根因

进入价格统计后，窗口会自动增高到屏幕可用高度。原页面固定分配 280pt 的顶部滚动区，
并在滚动区之外对多行计价说明使用纵向 `fixedSize`。macOS 通过零尺寸提议探测页面最小尺寸时，
说明被测成极窄的长列；真实 `NSHostingController.sizeThatFits(in: .zero)` 回归测试测得最小高度为 **1232pt**。

## 当前布局

- 请求明细与价格统计复用 `CPAUsageDetailPage`，只消费导航目的地已分配的尺寸，不修改 `NSWindow`。
- 筛选、指标、完整说明、表格和分页底栏置于同一个纵向 `ScrollView`，整页一起滚动。
  外层 `GeometryReader` 约束页面视口，内容高度不再抬高窗口下限。
- 表格标题、数据区和底栏统一放进 `CPAUsageTableCard`，复用主题底色、14pt 连续圆角及阴影。
- 原生 `Table` 使用 inset 样式，关闭交替行底色和独立滚动背景；保留列宽调整、横向滚动、键盘与辅助功能。
  局部 AppKit 测量器读取末行边界、表头、边距和常显水平滚动条高度，让当前页纵向内容完整展开。
  不使用被旧视口撑住的文档高度；当前页内容布局身份变化会触发重新测量，末页行数减少时正确收缩。
  测量器不接管原生代理或数据源，异步合并几何通知并去重高度，离开窗口时解绑观察。
- 数值右对齐并使用等宽数字。价格编辑与模型名称同行，展开单价列时在表格标题右侧展示单价单位，计费公式位于底栏。
- 请求状态使用文字、符号与轻量胶囊底色。历史切换在表格标题区，分页和历史总数在同卡底栏；窄窗口分页可换行。
- 单次请求、历史日汇总、模型价格统一每页最多 **20 条**，通过上一页／下一页切换，没有无限滚动和可增大页容量的选项。
  单次请求在数据库使用分页查询；历史与价格从完整聚合结果取当前页，顶部摘要、覆盖率与费用仍基于完整筛选结果。
  修改筛选回到第一页；结果减少时校正到有效页码。
- 默认价格表四列、请求表五列、历史表四列。提供商并入模型次级文字；请求日期与时分秒分两行，详情按钮与模型同行。
  表格宽度达到 820pt 时补充单价列，达到 860pt 时补充请求 TTFT/TPS；阈值只控制展示，不触发查询或采集。
  全部请求指标仍可在详情查看，完整价格仍可在编辑面板查看；长模型、提供商和费用有悬停全文。
- 两页四项摘要统一采用四列／两列自适应排布，避免三项加一项的孤行。

价格编辑、历史覆盖及费用下界的业务语义保持原样，没有新增采集或缓存。

## 验证记录

- 原实现：`CPAUsageDetailLayoutTests` 中价格页高度回归失败，1232pt 超过紧凑窗口的 480pt 下限。
- 修复后：两个页面的零尺寸探测以及 600×480、780×620 内容区测量通过。
- 先前窗口约束与表格样式修复：`CPAUsageDetailLayoutTests`、`CPAUsageHistoricalDetailTests`、`CPAUsageDashboardTests` 共 **24 项通过，0 失败**。
- 使用独立临时数据库和合成数据，检查价格页深浅色、请求列表与历史汇总四种渲染；
  内容区为 680×600、760×620 和 1060×720，数据加载后尺寸保持稳定。
- 临时渲染入口不进入正式测试目标或应用，回归测试不读取用户统计数据库。
- 先前表格样式版本的 Release 通用二进制（arm64 / x86_64）构建通过，应用完整签名验证通过；独立只读评审无阻断问题。

### 整页滚动与每页 20 条回归

- `CPAUsageDetailLayoutTests`、`CPAUsageTablePageTests`、`CPAUsageHistoricalDetailTests`、`CPAUsageDashboardTests`
  共 **32 项通过，0 失败**（macOS 26.5.2、arm64）。
- 真实 `NSWindow` 承载生产页面／卡片组件，从原生表格发送纵向滚轮事件，外层页面移动而表格纵向位置保持不变；
  横向事件仍推动宽表，600×500 内容区保持原尺寸。
- 验证 20 行变 1 行后高度收缩、同条数内容增高后重新测量、替换原生表格后空态回到 220pt；
  同窗口两张表分别测量自身高度，常显水平滚动条不遮挡末行。
- 45 条真实请求分三页返回 20／20／5 条且无重复遗漏，各页总数和 Tokens 保持全量。
  45 个历史模型与价格模型也分三页显示，历史总数、请求覆盖和总费用保持完整。
- 包含空结果、整页边界、越界页码、结果缩短和极大计数验证；测试仅使用独立临时数据库和合成数据。
- 独立只读复核检查了分页、测量通知的生命周期和表格归属，没有发现阻断问题。
- 宽度追加验证：三个真实业务表均在 600pt 内容区（表格可用 560pt）完整显示主要列；
  请求与价格页面从 600pt 扩到 1000pt，再缩回 600pt，列数按阈值恢复且没有横向溢出，始终保持每页 20 条。
- 连同更新与图表回归，最终相关检查 **53 项通过，0 失败**，构建目标为 macOS 15.0／arm64，实际运行于 macOS 26.5.2。

- 覆盖发布前全量回归：**681 项通过、0 失败、1 项手动内存基准按设计跳过**（macOS 26.5.2／arm64）。
