# 统计概览融合与趋势布局优化

2026-10-14：在「统计分析 → 客户端与调用」中移除整页“维度”切换，减少多层卡片和重复布局；同时修正「用量统计 → 用量趋势」的重复卡片外壳。

## 页面变化

- 来源与时间继续使用项目定义的胶囊分段控件，自定义日期和原偏好不变。
- 六项客户端指标与五项调用指标连续排列在一张「统计概览」卡内，各项不再单独绘制卡片背景或阴影。
- 常规宽度按 4＋4＋3 排列；窄窗口自动减列，允许末行空位，避免十一项因无法整除而退化成一列。
- 统一数字字号与间距，用系统自适应颜色和轻量图标区分指标；悬停与辅助功能保留未缩写数值。
- “总调用”明确为“工具调用总数”，“活跃 MCP”明确为“已调用 MCP 数”，“未调用技能”明确为“未调用技能数”。后两项仍按当前来源／时间范围统计，不表示服务器在线状态或技能总量。
- CPA 趋势图只使用 `CPAUsageTrendChart` 自身的 `quotioCard`，父层不再重复添加背景、阴影和内边距。

## 数据与功能兼容

客户端 Token 与工具调用继续使用各自账本，不合并原始事件，也不把缓存额外加到总 Token 中。两类数据分别判定可用性：来源未读到显示“—”；来源成功读取但筛选后无记录显示确切的零。Pi 缺失的推理指标和读取不完整时的未调用技能计数仍保留未知。

旧 `clientAnalytics.ui.section` 偏好保留在磁盘，统一页面不再用它隐藏模块。删除原三分支及重复摘要组件；单日 Token 趋势继续显示，调用日趋势仍遵循原单日隐藏规则。

保留调用趋势、Token 趋势、热力图与悬停、模型图表和完整模型明细、MCP／技能／工具排行及下钻、代理会话次数、未调用清单、采集详情、扫描／取消和异常提示。统计根页面的导航切换、后台采集和查询生命周期不变；CPA 趋势的图例、悬停及统计查询代码未改。
