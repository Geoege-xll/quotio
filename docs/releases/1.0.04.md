# QuotioPlus 1.0.04

本版全面转向 CLIProxyAPI 8.x，并修复代理启停、服务商同步、账号与监控状态的多处问题。继续保留 QuotioPlus 现有架构和界面。

构建号：**81**。适用平台：**macOS 15.0 及以上、Apple Silicon（arm64）**。

## 本次更新

- **CPA 8 管理与迁移**：只安装和运行 8 系列；旧配置通过官方管理接口迁移，并在首次迁移前保留备份。客户端密钥、上游凭据和模型别名按 v8 布局处理，局部配置写入保留未触及的注释和手工设置。
- **启动与服务商同步更可靠**：修复服务商 URL 的斜杠转义导致 CPA 返回 `invalid_body` 的问题。若同步仍失败，已通过健康检查的 CPA 会保持运行，界面显示上游校验原因，待下次同步重试。
- **启停状态更准确**：修复状态栏开关的实时状态、重复点击、停止时会话失效闪退，以及启动期间停止后难以重新开启的问题。取消旧启动请求，防止过期结果写回。
- **账号与额度显示修复**：修正账号头像字母位置、active 状态颜色和账号额度总数翻倍；Antigravity 模型耗尽时显示受影响模型及原因。完善监控模式配额刷新。
- **日志与仪表盘**：文件日志关闭时不再因进入日志页触发 HTTP 400；仪表盘顶部保留 CPA 运行服务，导航刷新时切换为进度菊花，服务错误显示在性能指标之前。
- **智能体与技能管理**：清理缓存和刷新期间显示整按钮进度；技能管理改为检测更新并在条目中提示，展示技能自身更新时间，移除重复名称标签。
- **维护性与凭据兼容**：拆分大型代理管理器和智能体管理视图；隔离旧登录钥匙串的兼容调用，保留外部 CLI 凭据读取时不弹出授权框的行为。

## 安装与更新

- 下载 `QuotioPlus-1.0.04.dmg` 或 `QuotioPlus-1.0.04.zip`，将 `QuotioPlus.app` 放入“应用程序”目录并替换旧版。Bundle ID 仍为 `com.app.george.quotioplus`，已有本地设置和数据无需重置。
- 发行包的 Developer ID 签名、公证及自动更新状态以发布页的构建说明为准；未配置相应凭据时使用临时签名，并通过发布页手动更新。
