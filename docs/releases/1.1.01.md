# QuotioPlus 1.1.01

本版本为 QuotioPlus 重大功能与交互升级，新增可视化路由中心与拓扑链路、全面升级统计分析看板与智能体工作区存储管理，优化账号管理融合界面，并确立全新的 macOS 原生微胶囊设计系统规范。

构建号：**1.1.01.1**。适用平台：**macOS 15.0 及以上、Apple Silicon（arm64）**。

## 本次更新

- **路由中心（Routing Center）与拓扑监控**：
  - 增加可视化的服务拓扑链路展示（客户端智能体 → 本地 CPA 代理 → 上游模型提供商），实时掌握路由与分发状态。
  - 最近一次执行追踪升级：详细记录上下游各阶段状态、延迟与消耗；失败详情直接就地渲染展示，无需手动点击折叠展开，快速排查链路问题。
- **统计分析看板与多源用量**：
  - 整合多客户端（Claude Code、Codex CLI、OpenCode、Pi 等）用量分析，实时汇总请求总量、Token 明细与平均延迟。
  - 提供细粒度的趋势折线图与活动分布热力图，支持按时间范围与来源灵活筛选。
- **智能体工作区与存储深度维护**：
  - 新增智能体缓存与空间透视卡片，透明化呈现各 CLI 客户端的磁盘空间占用与会话存储。
  - 支持一键安全清理过期缓存与历史数据，保障本地运行性能。
- **账号管理与配额池**：
  - 全面融合账号卡片与配额条，清晰呈现各渠道账号配额比例、重置倒计时及 IDE 绑定指示。
  - 优化 Antigravity、Claude、OpenAI、Copilot 等多服务商账号的同步与状态监测。
- **UI 设计系统与交互规范升级（外方内圆）**：
  - 确立 `[des-commit-001]` 行内输入提交规范与 `QuotioInlineApplyField` 通用控件。
  - 优化设置中“上游代理”等单字段配置的交互布局，删除外部冗余示例文本，统一采用内部原生 placeholder 与微胶囊应用按钮。
  - 支持变更基线感知（Dirty Tracking），回车与按钮同构触发异步保存，带来丝滑顺畅的平台一致性体验。
- **架构治理与稳定性强化**：
  - 遵循 5 层架构标准（App / BusinessModules / Shared / Infrastructure / Resources），实现高内聚、单向依赖与模块解耦。

## 安装与更新

- 下载 `QuotioPlus-1.1.01.dmg` 或 `QuotioPlus-1.1.01.zip`，将 `QuotioPlus.app` 放入“应用程序”目录并替换旧版。Bundle ID 为 `com.app.george.quotioplus`，已有本地设置与数据库无缝迁移，无需重置。
- 发行包的 Developer ID 签名、公证及自动更新状态以发布页的构建说明为准；未配置相应凭据时使用临时签名，并通过发布页手动更新。

## 验证

- 经 macOS 15+ Apple Silicon 真实设备验证与定向架构测试，所有交互控件与链路渲染均运行正常。
