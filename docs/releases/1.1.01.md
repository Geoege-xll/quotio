# QuotioPlus 1.1.01

本版本为 QuotioPlus 重大功能与交互升级，新增可视化路由中心与拓扑链路、全面升级统计分析看板与智能体工作区存储管理，优化账号管理融合界面，并确立全新的 macOS 原生微胶囊设计系统规范。

构建号：**1.1.01.5**（2026-10-18 替换发行包）。适用平台：**macOS 15.0 及以上、Apple Silicon（arm64）**。

## build 1.1.01.5 修复

- **CPA 自动刷新周期**：定时到期后不再被最近刷新时间二次拦截，避免额度更新延后一轮；账号管理与菜单栏继续通过同一快照同步更新。
- **持续刷新与初始化**：修复慢速本地初始化覆盖 CPA 定时任务的问题。管理器内部重启时旧轮作废，后续周期继续读取新会话；API Key 列表失败或编辑中不再阻断额度查询。
- **原有功能与配置**：保留启动首轮、手动刷新、全部周期选项、账号、配置、额度映射及原状态／任务所有权，不新增后台轮询任务。

## build 1.1.01.4 修复

- **Antigravity 周额度与五小时额度**：修复第二账号周额度持续显示已用 0% 的问题。采用与 CPA 官方客户端一致的 Hub 请求身份，从实际执行环境同一次汇总读取两个周期及各自重置时间，避免正式环境的满额或旧读数混入。
- **统一取数与异常边界**：本地直连和 CPA 转发共用无状态读取契约，删除上一构建的跨环境周期拼接及模型补查；保留精确账号、存量项目优先、取消和迟到响应隔离。执行端点不可用时按原宿主规则处理失败，不以其他环境满额冒充成功。
- **耗尽与未知值兼容**：正确识别上游省略耗尽零值的情况；显式 null、布尔、非有限数或畸形字段继续保持未知，独立额度池与旧缓存保持兼容。
- **原有配置与布局**：保留账号、项目、配置、主窗口、账号页及菜单栏的显示方式、CPA v8 管理转发和原状态／任务所有权。

## build 1.1.01.3 历史修复

该构建的临时校准取数已由 build 1.1.01.4 的统一 Hub 汇总替代，以下保留当时的改动记录。

- **Antigravity Gemini 五小时额度与重置时间**：修复正式汇总固定显示 100%、重置时间随每次刷新向后推五小时的问题。周额度继续使用真实汇总，五小时百分比与重置时间从同一凭据、同一项目的实际运行环境成对校准。
- **失败与独立池兼容**：补查失败显示未知，不继续误报满额；模型读数不同时保留独立额度，不平均或覆盖周额度，并兼容耗尽时省略的零值。
- **原有功能与配置**：保留账号、历史配置、CPA v8 管理接口、菜单栏与账号页共同快照、取消校验及原状态和任务所有权。

## build 1.1.01.2 修复

- **动态模型目录与已有配置保留**：配置候选从当前服务实时读取，取消静态型号注入；完善首次配置、空目录和失败重试，保留历史模型、手动输入、未知配置字段及 Claude 原生角色。CPA 管理接口继续使用 v8，客户端模型目录仍沿兼容协议使用 `/v1/models`。
- **配置并发与会话隔离**：快速切换客户端、关闭重开及连续刷新时，旧目录、连接测试、预览、保存和备份恢复结果不能覆盖新表单。Pi 自动保存与恢复增加原服务内互斥，避免文件事务交错，并保留原双文件回滚。
- **菜单栏与账号额度**：修复 Antigravity Gemini 额度读取兼容问题；优化真实级联子菜单的刷新布局，保留账号额度明细、Codex 分析及原有账号卡片布局。

本次按维护者要求替换既有 `v1.1.01` 发行资产并同步标签；原 build `1.1.01.4` 源码提交 `21e7e0510672ff66e6b8c6bf407946b8f4149d42` 及更早历史继续保留。

## 本次更新

- **路由中心（Routing Center）与拓扑监控**：
  - 增加可视化的服务拓扑链路展示（客户端智能体 → 本地 CPA 代理 → 上游模型提供商），实时掌握路由与分发状态。
  - 最近一次执行追踪升级：详细记录上下游各阶段状态、延迟与消耗；失败详情直接就地渲染展示，无需手动点击折叠展开，快速排查链路问题。
- **统计分析看板与多源用量**：
  - 整合多客户端（Claude Code、Codex CLI、OpenCode、Pi 等）用量分析，实时汇总请求总量、Token 明细与平均延迟。
  - 提供细粒度的趋势折线图与活动分布热力图，支持按时间范围与来源灵活筛选。
- **智能体工作区与存储深度维护**：
  - 新增智能体缓存与空间透视卡片，透明化呈现各 CLI 客户端的磁盘空间占用与会话存储。
  - 支持一键安全清理过期缓存与历史数据，保障本地运行性能。
- **账号管理与配额池**：
  - 全面融合账号卡片与配额条，清晰呈现各渠道账号配额比例、重置倒计时及 IDE 绑定指示。
  - 优化 Antigravity、Claude、OpenAI、Copilot 等多服务商账号的同步与状态监测。
- **UI 设计系统与交互规范升级（外方内圆）**：
  - 确立 `[des-commit-001]` 行内输入提交规范与 `QuotioInlineApplyField` 通用控件。
  - 优化设置中“上游代理”等单字段配置的交互布局，删除外部冗余示例文本，统一采用内部原生 placeholder 与微胶囊应用按钮。
  - 支持变更基线感知（Dirty Tracking），回车与按钮同构触发异步保存，带来丝滑顺畅的平台一致性体验。
- **架构治理与稳定性强化**：
  - 遵循 5 层架构标准（App / BusinessModules / Shared / Infrastructure / Resources），实现高内聚、单向依赖与模块解耦。

- 下载 `QuotioPlus-1.1.01.dmg` 或 `QuotioPlus-1.1.01.zip`，将 `QuotioPlus.app` 放入“应用程序”目录并替换旧版。Bundle ID 为 `com.app.george.quotioplus`，已有本地设置与数据库无缝迁移，无需重置。
- 发行包的 Developer ID 签名、公证及自动更新状态以发布页的构建说明为准；未配置相应凭据时使用临时签名，并通过发布页手动更新。
- 本次 build `1.1.01.5` 使用 **ad-hoc 临时签名，未做 Apple 公证**；未启用 Sparkle 自动安装，请通过发布页下载替换。
