# QuotioPlus 1.0.01

QuotioPlus 1.0.01 发行版本，基于 Quotio 进行深度二次开发与体验优化。

## 本次更新

本版本构建号为 **75**，适用于 **macOS 15.0+、Apple Silicon（M1 或更新芯片，arm64）**。

- **智能体管理与技能发现**：
  - 在“技能管理”页面标题区新增胶囊分段视图（Segmented Control），实现“已纳管技能”与“从 GitHub 发现”的独立无缝切换，分类浏览与管理更加清晰。
- **技能更新时间修复**：
  - 修复已纳管技能更新时间异常显示为“更新于 1年1月1日”的缺陷。系统现直接读取真实文件系统的最近修改时间，若无有效更新时间则自动隐藏，不再显示错误默认时间。
- **仪表盘体验重构**：
  - 重构仪表盘布局，将“性能与吞吐”指标卡片置顶呈现（形态 B），脱离 Cap 统计联动，提供实时的请求响应与吞吐看板。
  - 移除不适用的用量折线图，精简并统一用量分布筛选器的联动逻辑，提升界面绘制性能与交互流畅度。
- **客户端与模型配置优化**：
  - 优化 Claude Code / Codex 模型映射与默认模型显示体验。
  - 增强 SQLite 本地用量状态安全与数据持久化机制。
- **打包规范与应用命名**：
  - 规范打包产物命名为 `QuotioPlus`（`QuotioPlus-1.0.01.dmg` / `QuotioPlus-1.0.01.zip`），统一应用包名为 `QuotioPlus.app`，并在系统与 Finder 中始终以 **QuotioPlus** 呈现。

## 安装与数据

- 平台要求：macOS 15.0 及以上版本，Apple Silicon（arm64）。
- 安装包：`QuotioPlus-1.0.01.dmg` / `QuotioPlus-1.0.01.zip`。
- 应用显示名称：**QuotioPlus**，Bundle ID：`com.app.george.quotioplus`。
- 已有本地数据和设置完全兼容，无需重置。

## English Release Notes

QuotioPlus 1.0.01 brings streamlined agent and skill management, refined dashboard telemetry, and improved application packaging.

- **Agent & Skill Management**: Added a capsule segmented control in the Skill Management header to toggle smoothly between "Managed Skills" and "Discover on GitHub".
- **Skill Timestamp Fix**: Resolved the issue where managed skills showed an erroneous timestamp ("Jan 1, 1"). Valid filesystem modification dates are now displayed, and invalid timestamps are safely hidden.
- **Dashboard Refactor**: Placed performance and throughput telemetry at the top (Mode B), unlinked from Cap selection. Removed the redundant usage trend line chart and unified distribution filter interactions.
- **Client & Model Settings**: Improved Claude Code / Codex model mapping and default model selection, with enhanced SQLite usage state safety.
- **Standardized Packaging**: Release artifacts are now named `QuotioPlus` (`QuotioPlus-1.0.01.dmg` / `QuotioPlus-1.0.01.zip`), and the application bundle is standardized as `QuotioPlus.app`.
