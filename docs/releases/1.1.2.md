# QuotioPlus 1.1.2

本版本为 QuotioPlus 稳定性与数据分析功能升级，优化客户端调用概览与工具指标，修复 Swift 6 并发安全问题，完善 OpenAI 官方 responses 协议路由分发及分析看板热力图呈现。

构建号：**1.1.2.1**（2026-11-14）。适用平台：**macOS 15.0 及以上、Apple Silicon（arm64）**。

## 本次更新亮点

- **客户端调用统计优化与去 Token 化**：
  - 客户端调用概览彻底移除“未调用技能”标签与本地 Token 消耗统计。
  - 聚焦总调用数、MCP 调用、技能调用与活跃 MCP 四项核心工具调用指标，支持自适应单行/双行网格排版与未知状态保护。
- **Swift 6 并发安全与钥匙串隔离修复**：
  - 修复 `KeychainHelper` 中非 MainActor 上下文访问 MainActor 隔离属性的编译器报错，确保后台凭据读取与监控任务并发安全。
- **OpenAI 官方 Responses 协议与路由适配**：
  - 支持 OpenAI 官方 responses 协议的路由分发与上下文透传，增强跨服务商模型映射与上游拓扑实时感知。
- **分析看板热力图与日趋势对齐**：
  - 校准 CPA 用量热力图展示边界与客户端调用日趋势统计，强化数据模型聚合与跨时区渲染鲁棒性。
- **CPA 账号管理与上游官方客户端基线核对**：
  - 对齐 v8.0.69 核心功能与认证文件流转，保持各项元数据与调度状态一致。
