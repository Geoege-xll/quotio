# QuotioPlus 1.0.02

QuotioPlus 1.0.02 发行版本，带来智能体管理、会话安全删除与技能仓库源等多项功能优化与稳定性提升。

## 本次更新

本版本构建号为 **76**，适用于 **macOS 15.0+、Apple Silicon（M1 或更新芯片，arm64）**。

- **会话管理与级联删除进度**：
  - 新增会话与子智能体任务删除进度弹窗（`WorkspaceSessionDeletionProgressSheet`），提供实时操作状态、耗时统计与任务计数，彻底避免重复操作与状态竞争。
  - 完善智能体历史会话树状拓扑关系与级联删除安全预检，保障本地 SQLite 数据库与文件系统原子一致性。
- **技能管理与仓库源分组**：
  - 纳管技能列表新增按 GitHub 来源仓库折叠分组展示，界面层次更清晰直观。
  - 增加来源仓库地址快捷跳转入口，便于直接在浏览器中查看技能上游源码与最新动态。
  - 优化技能源自动修复工具（`repair_skill_sources.py`）。
- **窗口与界面交互打磨**：
  - 调整主窗口默认与最小尺寸为更加精炼的 960x600，进一步优化紧凑型屏幕与高分屏下的排版呈现。
  - 补充并更新多语言本地化文案（`Localizable.xcstrings`）。
- **打包与独立分发标准**：
  - 沿用统一的 `QuotioPlus` 独立分发标准，生成标准 DMG 与 ZIP 格式发布包。

## 安装与数据

- 平台要求：macOS 15.0 及以上版本，Apple Silicon（arm64）。
- 安装包：`QuotioPlus-1.0.02.dmg` / `QuotioPlus-1.0.02.zip`。
- 应用显示名称：**QuotioPlus**，Bundle ID：`com.app.george.quotioplus`。
- 已有本地数据和设置完全兼容，无需重置。

## English Release Notes

QuotioPlus 1.0.02 brings enhanced workspace session management, grouped skill repositories, and polished interface layouts.

- **Workspace Session Deletion Progress**: Added a dedicated progress sheet for session and subagent cascade deletions with real-time feedback and state locking to prevent concurrency races.
- **Grouped Skill Repositories**: Organized installed skills by source GitHub repositories with direct repository links for streamlined exploration.
- **Window Sizing & Localization**: Tuned default window dimensions to 960x600 for improved compact display fitting, alongside refreshed localization strings.
- **Packaging Integrity**: Standardized release builds for Apple Silicon (arm64) requiring macOS 15.0+.
