# QuotioPlus 1.0.03

本版本集中改进账号刷新、凭据保护和菜单栏体验，并选择性移植上游 v0.32.0 及其后的适用修复，继续保留 QuotioPlus 的现有架构、工作区管理和用量统计功能。

构建号：**77**。适用平台：**macOS 15.0 及以上、Apple Silicon（M1 或更新芯片，arm64）**。

## 本次更新

- **删除和禁用账号更可靠**：修复旧刷新请求返回后恢复已删除额度、订阅或账号列表的问题；连续操作不同账号时，每项操作都能正确保存。
- **Codex 多来源账号统一识别**：同一账号的原生文件、钥匙串和自有凭据合并显示，同邮箱不同账号保持独立，切换登录不会串用旧额度。
- **Codex 禁用状态完整生效**：禁用账号后停止相关额度查询、令牌刷新和重试；来源变化后仍可正常启用，钥匙串暂不可读时保留已有账号和缓存。
- **Claude 外部凭据保护**：尊重 CLI、钥匙串和 Desktop 的凭据归属，避免不必要的令牌刷新或覆盖；外部认证失效时保留上次成功额度。
- **菜单栏筛选更稳定**：切换提供商时直接更新菜单项可见性，减少菜单重建引起的交互异常。
- **额度格式兼容性提升**：支持 Amp 新版金额与订阅额度，完善 Kiro 区域校验及 Antigravity 过期时间解析。
- **刷新与回退细节修复**：取消 IDE 刷新后不再写回旧结果，预热错误保留到下次执行，代理回退失败时保留原版本文件。

## 安装与更新

- 安装包：`QuotioPlus-1.0.03.dmg` 或 `QuotioPlus-1.0.03.zip`。
- 将 `QuotioPlus.app` 放入“应用程序”目录并替换旧版。应用身份继续使用 `com.app.george.quotioplus`，本地设置和数据无需重置。
- 本发行包沿用临时签名，未经 Developer ID 签名和 Apple 公证；macOS 可能要求额外确认。
- 沿用发布页手动下载安装，不提供 Sparkle 自动安装更新包。
