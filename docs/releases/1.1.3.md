# QuotioPlus 1.1.3

构建号 **114**。适用平台为 **macOS 15.0 及以上、Apple Silicon（arm64）**。

本构建替换首发构建 113。

- 移除「仅监控」运行模式和切换入口。首次引导及旧模式偏好统一使用本地代理，旧监控额度历史仍可查询。
- 更新账号页与菜单栏的额度刷新和缓存恢复，完善 Copilot、Cursor、Kiro 和 Trae 的额度读取。
- 加强本地代理的端口归属校验与启停处理，避免终止独立运行的进程。
- 调整 CPA 用量筛选、统计与热力图，完善客户端调用统计的历史数据读取。
- 改进工作区会话列表和技能更新流程，支持逐项忽略待纳管的本地技能。

本版本同时包含基于 1.1.2 源码的首发改动。与 1.1.02 相比，主要变化包括以下几项。

- 客户端调用概览聚焦总调用、MCP 调用、技能调用和活跃 MCP 四项指标。
- 修复后台钥匙串读取的 Swift 6 隔离问题。
- 完善 OpenAI 官方 Responses 协议的路由和上下文透传。
- 调整 CPA 用量热力图和客户端调用日趋势的显示。

发行构建号改用纯数字，与现有 GitHub Actions 打包校验一致。
