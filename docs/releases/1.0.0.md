# QuotioPlus 1.0.0

QuotioPlus 首个独立发行版本，基于 [Trong Nguyen 的 Quotio](https://github.com/nguyenphutrong/quotio) 二次开发。感谢原作者和所有贡献者提供的开源基础；原有版权声明、MIT 许可证和第三方许可证继续保留。

## 本次发布

本页软件包已按 **1.0.0（构建 74）** 重新制作并覆盖。最低要求调整为 **macOS 15.0+、Apple Silicon（M1 或更新芯片）**，不再提供 Intel 版本；原构建 73 为 macOS 14+ 通用包。

- 全新午夜蓝猫咪图标，与应用 UI 配色一致；GitHub 首页提供中英文说明与当前版本实拍截图。

- 优化仪表盘布局、概览指标和筛选交互，支持折叠筛选区及完整筛选弹窗。
- 默认窗口下，仪表盘主指标和次级指标组优先一行四等分；窄窗口保留两列换行及原有数值格式。
- 请求明细和价格统计整页滚动，三个列表统一每页最多 20 条，使用上一页／下一页；顶部汇总始终覆盖完整筛选结果。
- 收敛默认表格列宽，提供商并入模型信息、时间拆成两行，次要指标在宽窗口展开或通过详情查看；修复价格页自动撑高窗口。
- 优化用量图表悬停与绘制，趋势图显示点数设上限并保留峰谷，减少大历史数据导致的卡顿；完整统计数据保留。
- 修复请求明细、价格统计及多项用量统计口径，明确区分未知数据与真实零值。
- 完善 Claude Code、Codex、OpenCode、Pi 的本地 Token 统计及工具、MCP、技能调用分析。
- 改进 Pi 安装检测与数据读取，兼容 Homebrew、npm 等安装方式。
- 统一统计到 SQLite，改用持久化汇总和增量处理，减少大规模历史数据的重复采集与内存占用。
- 新增「存储与数据」维护页，支持清理缓存、按模块清除统计和回收数据库空闲空间。
- 完善账号、配额、提供商、模型映射及智能体配置界面，统一原生控件与交互样式。
- 应用使用独立身份 QuotioPlus 和自有更新地址，原项目更新检查移至「诊断与维护」。

## 安装与数据

支持 macOS 15 及以上版本，仅支持 Apple Silicon（arm64）。安装包名称沿用 `Quotio-1.0.0.dmg`／`Quotio-1.0.0.zip`，应用显示名称为 **QuotioPlus**，Bundle ID 为 `com.app.george.quotioplus`。已安装旧包的用户请从本页重新下载并替换应用。

已有本地统计会继续使用并进行必要迁移；大历史首次整理可能需要等待。清理缓存会保留统计历史；清除统计需要确认，且现存源日志可在后续采集重新导入。

构建 74 的本机完整回归 681 项通过、0 项失败（macOS 26.5.2／arm64）；需要显式隔离数据的 1 项手动性能基准按设计跳过，该大规模历史基准此前已单独通过。基准结果不代表完整应用在所有设备上的长期内存上限。

## English release notes

QuotioPlus 1.0.0 is the first independent release of our derivative of [Quotio by Trong Nguyen](https://github.com/nguyenphutrong/quotio). Thank you to the original author and open-source contributors. Original copyright notices and licenses are retained.

- A new midnight-blue cat icon matching the app palette, with English and Chinese repository pages and current-version screenshots.
- Refined dashboard layouts, collapsible filters, request details, pricing estimates, and metric definitions.
- Four-column dashboard metrics at the default window size, with the existing two-column fallback for narrower windows.
- Whole-page scrolling for request details and pricing, with fixed 20-row pagination and totals calculated over all matching records.
- Compact default table columns, with provider information below model names and secondary fields available in wide windows or detail panels. Opening pricing no longer enlarges the window.
- Reduced chart hover and rendering overhead, including bounded trend plots that retain peaks and valleys while keeping the full underlying statistics.
- Local usage and call analytics for Claude Code, Codex, OpenCode, and Pi, including improved Pi installation detection.
- Shared SQLite storage, persisted summaries, and incremental processing to reduce repeated scans and memory use.
- Storage maintenance for clearing caches, removing statistics by module, and reclaiming database space.
- Independent QuotioPlus application identity and update source, with upstream release checks in Diagnostics & Maintenance.

The assets on this page have been rebuilt as **1.0.0 (build 74)**, requiring **macOS 15 or later and Apple Silicon (M1 or later)**. Intel is no longer supported; the original build 73 was a macOS 14+ universal build. Download `Quotio-1.0.0.dmg` or `Quotio-1.0.0.zip` again to replace an older installation. The app is displayed as **QuotioPlus**, with Bundle ID `com.app.george.quotioplus`.

The build 74 full regression suite passed 681 tests with no failures on macOS 26.5.2 / arm64. One manual benchmark requiring isolated fixtures is intentionally skipped in the regular suite and was validated separately. Existing local statistics are retained and migrated as needed; clearing caches preserves history, while retained source logs can be imported again after statistics are cleared.
