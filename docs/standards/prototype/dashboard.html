Page design and interaction contract

页面目的与布局

本地代理仪表盘按 CPA 运行服务 → 条件新手引导 → 四项低强调统计 → CPA 可用模型 → 现有隧道信息排序。运行卡标题在左，右侧同组依次为运行状态、启动/停止按钮；地址下方仅保留刷新与 /v1 复制。合并旧 API 地址区域，保留 /v1 复制。提供商汇总已迁移到提供商页面。运行状态和模型真实性优先于装饰；借鉴 AIUsage 分组网格，不新增业务能力。模型区域最底部在说明与详情之后设置页脚：左侧已展示/总数，右侧带边框的展开全部模型/收起模型按钮。

页面导航

侧边栏在两个固定页面之间导航；其它侧边栏文字是现有页面的背景定位，不提供伪导航。演示条、构造数据与契约不进入生产。

交互

  • theme：选择浅色或深色，立即切换两套语义色阶；仅原型演示控件。
  • nav-dashboard：打开仪表盘原型 dashboard.html。
  • nav-providers：打开提供商原型 providers.html。
  • tunnel-manage：展开现有隧道管理入口说明；保留实际管理按钮位置，原型不连接公网或改写隧道配置。
  • scenario：切换已声明演示状态，运行卡保留在首位；网络开放时改为“允许网络访问 · 本机连接地址”，未知 PID 明确未提供。
  • runtime-toggle：位于运行卡标题行右侧、紧随状态徽标；运行时显示停止中，完成后变为已停止并清空模型；停止时显示启动中，完成后加载模型；未安装时先演示安装；失败时重试。
  • runtime-refresh：显示正在刷新后更新运行状态与目录，繁忙状态禁用重复操作。
  • copy-base：复制本机基础地址 http://127.0.0.1:8317。
  • copy-api：复制客户端 API 地址 http://127.0.0.1:8317/v1。
  • model-refresh：运行时展示加载反馈，刷新失败保留旧目录并注明旧数据，首次失败不显示模型；停止或繁忙时禁用。
  • model-more：位于目录最底部右侧，以带边框按钮在初始每组最多三个模型和全部模型之间切换；有折叠条目时显示“展开全部模型”，已展开时显示“收起模型”。左侧同步已展示/总数。不提供搜索或过滤。
  • detail-copy：复制当前选中的完整原始模型 ID。
  • detail-close：关闭内联详情并把焦点还给刚才的模型按钮。
  • guide-dismiss：隐藏条件新手引导，不影响运行卡和统计。
  • guide-provider：打开原型内的提供商选择面板，可演示 OAuth 或 Vertex 文件导入入口。
  • guide-agent：展示已有 CLI 配置流程的入口说明；原型不改配置。
  • guide-oauth：演示现有 OAuth 授权进度与结果。
  • guide-import：演示现有 Vertex JSON 文件导入结果，不读取真实文件。

状态与适配

默认运行成功。状态菜单覆盖未安装、已停止、启动中、停止中、启动失败、未知 PID、网络开放、模型首次加载、空目录、首次失败、旧数据失败、首次引导。停止清空目录，失败不伪造条目；旧目录显式标识上次更新。复制失败有反馈。不提供搜索及无匹配状态；页脚计数反映展开或收起后的已展示数和全部目录总数，无目录时隐藏页脚。四项指标保留原副说明，首次引导不替代提供商汇总。 所有状态使用文字而非仅颜色；键盘 Tab 可到达控件，焦点环可见。窄窗口侧栏折为顶栏、统计折为两列、模型折为单列，长 ID 在详情换行。浅深色均使用系统字体，支持文本缩放和减少动态效果。

例外与边界

无特殊规范例外。页面完全离线，所有数字、账号、状态和模型均为明确构造的演示数据；不访问真实 API、文件或凭据。复制仅复制公开演示文本；浏览器禁止剪贴板时提示手动选择，不伪报成功。监控模式、真实账号管理与代理副作用沿用生产既有逻辑，不由原型重新定义。
